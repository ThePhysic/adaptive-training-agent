requires complete consistent hard-passing evidence. Actual total and human-quality

liability, not a repaired or replaced result. Binding/source conflicts stop review.

not administrator deletion, arbitrary database/workspace replacement or proven

No reset/delete/retry or alternative output-directory API is provided.
